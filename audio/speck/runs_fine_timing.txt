# EXPLORATORY (2026-11-21), not a final model: real spike timing for audio. The paper's audio decoders see one spike
# count per channel per 40 ms frame; the Speck SNN spreads that count over its ten 4 ms chip steps. Here each chip step
# gets the threshold crossings that actually fell in its 4 ms (audio/prepare_fine_bins.py, then
# build_word_dataset_daynorm.py --fine; the same cohort, frames and split, verified to sum back to the 40 ms counts).
#   FT1  P5's exact recipe, input = real 4 ms spikes as 0/1 events (no per-day normalization; chip-ready)
#   FT2  as FT1, each event weighted by 1 / its day's 40 ms SD (the per-day normalization; on a chip this needs
#        layer-1 weights reloaded per day, so it is judged in software only)
#   LS0  the LSNN streaming at 40 ms on its usual normalized features (the control for LS1: same batches)
#   LS1  the LSNN streaming at 4 ms (ten steps per frame) on the day-normalized 4 ms counts; input noise scaled by
#        1/sqrt(10) per step (offset by 1/10) so each 40 ms frame gets the noise LS0's frames get
# LS1 is the slowest (~10x LS0's steps), so it is listed first.
