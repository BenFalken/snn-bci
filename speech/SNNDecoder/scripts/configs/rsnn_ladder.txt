# Recurrent spiking network shaped like the paper's RNN (snnDecoder/rsnn.py,
# defaults in snnDecoder/configs/speech_rsnn.yaml: adaptive IAF (ALIF), soft
# reset, multi-spike, dropout 0.2 / 0.4, noise 1.0, one-step leaky readout).
# All causal except R1_replica_smoothed, which adds the RNN's non-causal input
# smoothing (sd 2 bins, ~120 ms lookahead) to measure what the lookahead is worth.
#
#   R1  32-bin stacking, stride 4 (80 ms steps), 5 x 1024 recurrent   the full replica
#   R2  32-bin stacking, stride 4,               2 x 512 recurrent    the GRU control's scale
#   R3  no stacking (20 ms steps),               2 x 512 recurrent    recurrence alone
#   R4  32-bin stacking, stride 4,               5 x 1024 feedforward the stacking window alone
# R3 steps every 20 ms, so its adaptation and readout time constants are 4x in steps.
R1_replica          | --config ../snnDecoder/configs/speech_rsnn.yaml
R1_replica_smoothed | --config ../snnDecoder/configs/speech_rsnn.yaml --smooth-sd 2
R2_small            | --config ../snnDecoder/configs/speech_rsnn.yaml --hidden-dims 512 512
R3_no_stack         | --config ../snnDecoder/configs/speech_rsnn.yaml --hidden-dims 512 512 --input-window 1 --input-stride 1 --tau-adapt 25 --temporal-decay-init 0.78
R4_feedforward      | --config ../snnDecoder/configs/speech_rsnn.yaml --recurrent false
