# Memory through the recurrence rather than long time constants: the ideas of DelayNet (Balafrej, Alibart & Rouat,
# "Expanding memory in recurrent spiking networks", arXiv 2310.19067). Their argument: long leak / adaptation /
# synaptic time constants hold the memory themselves, so the recurrent weights never learn to (on their benchmark,
# removing the recurrence changed little), and they are costly in hardware. Their alternative, shown on toy memory
# tasks (cue accumulation, permuted sequential MNIST) with 100-216 neurons:
#   recurrent delays     each neuron's spikes reach the others later: 0 ms (18% of neurons), 80 ms (42%),
#                        100 ms (40%) -- here 0, 4 and 5 steps of 20 ms. Gradients skip steps, like residual
#                        connections through time; delays are cheap on neuromorphic chips (a spike buffer)
#   wide surrogate       gradient 1 from one threshold below firing upwards ("ramp"; ours: single exponential)
#   branching factor     a loss on the step-to-step change in activity (keeps it steady) in place of a firing-rate
#                        penalty, which they argue holds back long-term learning; weight 10 is our guess at a
#                        moderate strength (their scale does not carry over), so it may need tuning
#   no self-connections  recurrent diagonal held at 0
# In their ablation, delays or the branching loss alone did not learn the task; so the combination runs too.
# Base: N3_full_linear (as native_memory): 2 x 1024 recurrent ALIF at 20 ms, the 256 features, RNN input layer.
#
#   N5_recdelay   + recurrent delays
#   N5_ramp       + wide surrogate
#   N5_branch     branching-factor loss (weight 10) instead of the spike-rate penalty
#   N5_delaynet   all four together
# Ordered for PACK=2.
